==================================================================
  Đưa WEBAPP CỦA BẠN (có tab API + AI Prompt) lên HF Spaces — FREE
==================================================================

>>> Đây là bản đúng giao diện + tính năng của bạn (FastAPI webapp).
>>> Dùng HF Spaces kiểu DOCKER. Chạy CPU/ONNX — KHÔNG cần GPU.

VÌ SAO PHẢI CHÉP webapp/ CỦA BẠN?
  Gói "vieneu" trên PyPI có sẵn 1 bản webapp CŨ (chưa có tab AI Prompt).
  Dockerfile sẽ cài engine giọng nói từ PyPI, rồi CHÉP ĐÈ thư mục webapp/
  của bạn lên — để chạy đúng giao diện + tính năng bạn vừa làm.

CẦN: 1 tài khoản Hugging Face (free): https://huggingface.co/join

------------------------------------------------------------------
SPACE CỦA BẠN CẦN 3 THỨ Ở THƯ MỤC GỐC:
------------------------------------------------------------------
  Dockerfile     <- lấy từ  deploy/hf-space-docker/Dockerfile
  README.md      <- lấy từ  deploy/hf-space-docker/README.md
  webapp/        <- COPY NGUYÊN thư mục webapp/ trong repo này
                    (chứa static/index.html, js/app.js... có tab AI Prompt)

------------------------------------------------------------------
CÁCH 1 — Kéo–thả trên web (không cần git)
------------------------------------------------------------------
  1. Vào: https://huggingface.co/new-space
     - Tên: vieneu-studio
     - Chọn SDK = Docker  (chọn "Blank" / không template)
     - Hardware = CPU basic (Free)
     - Bấm Create Space.

  2. Mở tab "Files" của Space -> "Add file" -> "Upload files".

  3. Tải lên đúng cấu trúc:
     - Kéo file deploy/hf-space-docker/Dockerfile  -> đổi tên thành: Dockerfile
     - Kéo file deploy/hf-space-docker/README.md   -> đè README.md có sẵn
     - Kéo NGUYÊN thư mục webapp/ (cả thư mục) thả vào — HF giữ nguyên cây
       thư mục webapp/static/..., webapp/config/...

  4. Commit. Space tự build (~5–8 phút lần đầu, có tải model).

  5. Xong. App chạy tại:
     https://huggingface.co/spaces/<tên-bạn>/vieneu-studio
     Bấm tab "🔌 API" -> "🤖 AI Prompt" để kiểm tra tính năng của bạn.

------------------------------------------------------------------
CÁCH 2 — Dùng git (gọn cho người quen dòng lệnh)
------------------------------------------------------------------
  # Tạo Space Docker trống trên web trước (bước 1 ở Cách 1), rồi:

  git clone https://huggingface.co/spaces/<tên-bạn>/vieneu-studio
  cd vieneu-studio

  # Chép từ repo VieNeu-TTS sang (sửa đường dẫn cho đúng máy bạn):
  cp /duong-dan/VieNeu-TTS/deploy/hf-space-docker/Dockerfile .
  cp /duong-dan/VieNeu-TTS/deploy/hf-space-docker/README.md .
  cp -r /duong-dan/VieNeu-TTS/webapp .

  git add Dockerfile README.md webapp
  git commit -m "Deploy VieNeu webapp (API + AI Prompt)"
  git push

------------------------------------------------------------------
LƯU Ý
------------------------------------------------------------------
  - Trong tab AI Prompt, prompt tự lấy URL Space thật làm base URL,
    nên copy dán sang agent khác là gọi đúng API trên Space của bạn.
  - Lần đầu mở sẽ tải model (vài phút) + Space free "ngủ" khi rảnh,
    tự thức khi có người vào (chờ ~30–60s).
  - Sau này sửa giao diện: chỉ cần upload lại thư mục webapp/ là xong
    (không phải build lại engine).
  - Muốn nhanh hơn: nâng Hardware (CPU upgrade / GPU) — trả phí.

  Tài liệu: https://huggingface.co/docs/hub/spaces-sdks-docker

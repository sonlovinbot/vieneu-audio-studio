============================================================
  AI Audio Studio — Hướng dẫn macOS & Linux
============================================================

CÀI ĐẶT
  • macOS:  nhấp đúp file   install.command

    ⚠️ NẾU MACOS BÁO: "install.command" Not Opened /
       "Apple could not verify..." → KHÔNG PHẢI VIRUS. Làm 1 trong 3 cách:

    Cách 1 (macOS 15 Sequoia trở lên):
       - Bấm Done
       - 🍎 → System Settings → Privacy & Security
       - Kéo xuống mục Security → bấm "Open Anyway" → nhập mật khẩu
       - Nhấp đúp install.command lần nữa → "Open Anyway"
       (macOS 14 trở về trước: chuột phải install.command → Open → Open)

    Cách 2 (nhanh): mở Terminal, gõ   xattr -cr   (có dấu cách cuối),
       kéo thả thư mục này vào Terminal, nhấn Enter, rồi nhấp đúp lại.

    Cách 3 (không bao giờ bị chặn): xóa thư mục này, mở Terminal, dán:
       /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/sonlovinbot/vieneu-audio-studio/main/install-online.sh)"

  • Linux:  mở Terminal trong thư mục này, chạy:
                bash install.sh

Bộ cài sẽ tự động:
  - Cài công cụ "uv" (nếu chưa có)
  - Tải thư viện cần thiết
  - Tạo icon "AI Audio Studio" trên Desktop
  - Hỏi có muốn tự chạy khi mở máy không
  - Mở giao diện tại:  http://127.0.0.1:8001

LƯU Ý
  - Lần chạy ĐẦU TIÊN cần Internet để tải mô hình giọng nói
    (vài phút). Các lần sau chạy offline.
  - Bản mặc định chạy bằng CPU — không cần card đồ họa.
  - Linux: lần đầu nhấp icon trên Desktop có thể phải
    chuột phải → "Allow Launching" (cho phép chạy).

MỞ LẠI APP SAU KHI CÀI
  - Nhấp icon "AI Audio Studio" trên Desktop.
  - Hoặc chạy:  uv run vieneu-studio

KHÔNG THẤY ICON TRÊN DESKTOP?
  • macOS:  nhấp đúp   tao-shortcut.command
  • Linux:  chạy        bash tao-shortcut.sh
  Lệnh này tạo lại lối tắt trên Desktop mà KHÔNG cần cài lại.
  (Tự dò đúng thư mục Desktop kể cả khi tên bị đổi theo ngôn ngữ.)
